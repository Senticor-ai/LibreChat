# LibreChat k3d Local Testing Guide

Test LibreChat with self-hosted Infisical on your local machine before deploying to production!

## Why Local Testing?

✅ **Test complete deployment** - Full stack including self-hosted Infisical
✅ **Validate configuration** - Ensure everything works before production
✅ **Learn the system** - Understand how all components interact
✅ **No cloud costs** - Test entirely on your laptop
✅ **Fast iteration** - Deploy and test in minutes

## Prerequisites

### Required Software

- **Docker or Podman** - For running k3d
  ```bash
  # macOS
  brew install docker
  # Or: brew install podman

  # Linux (Ubuntu/Debian)
  curl -fsSL https://get.docker.com | sh
  # Or: sudo apt install podman
  ```
  **Note**: k3d works with both Docker and Podman. The bootstrap script only requires kubectl and helm.

- **k3d** - k3s in Docker
  ```bash
  # macOS
  brew install k3d

  # Linux
  curl -s https://raw.githubusercontent.com/k3d-io/k3d/main/install.sh | bash
  ```

- **kubectl** - Kubernetes CLI
  ```bash
  # macOS
  brew install kubectl

  # Linux
  curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl"
  chmod +x kubectl
  sudo mv kubectl /usr/local/bin/
  ```

### System Resources

- **RAM**: At least 8GB (16GB recommended)
- **Disk**: At least 20GB free space
- **CPU**: 4+ cores recommended

## Quick Start (5 Commands)

```bash
# 1. Create k3d cluster
k3d cluster create librechat-test --agents 1 -p "30080:30080@loadbalancer"

# 2. Verify cluster is running
kubectl get nodes

# 3. Clone repo (if not already done)
git clone <your-repo-url>
cd LibreChat/k3s-librechat-deployment

# 4. Run bootstrap script
cd scripts
./bootstrap-local.sh

# 5. Access LibreChat
# Open http://chat.127.0.0.1.nip.io:30080 in your browser
```

**Estimated time:** 10-15 minutes

## Detailed Setup Guide

### 1. Create k3d Cluster

```bash
# Create a new k3d cluster for LibreChat testing
k3d cluster create librechat-test \
  --agents 1 \
  -p "30080:30080@loadbalancer" \
  --k3s-arg "--disable=traefik@server:0"

# Verify the cluster is running
kubectl cluster-info
kubectl get nodes
```

**What this does:**
- Creates a k3s cluster running in Docker containers
- Exposes port 30080 for web access
- Disables Traefik (we'll use nginx-ingress instead)

### 2. Run Bootstrap Script

```bash
cd k3s-librechat-deployment/scripts
./bootstrap-local.sh
```

**The script will:**
1. Check prerequisites (kubectl, helm, docker)
2. Install/upgrade to Helm 4
3. Prompt for OpenAI/Anthropic API keys (optional)
4. Install nginx-ingress and cert-manager
5. Deploy self-hosted Infisical
6. Prompt you to set up Infisical (create account, project, secrets)
7. Install Infisical Operator
8. Configure secret synchronization
9. Deploy LibreChat with MongoDB and MeiliSearch
10. Display access URLs

### 3. Set Up Infisical

When prompted during the bootstrap script:

1. **Access Infisical**: Open `http://infisical.127.0.0.1.nip.io:30080`

2. **Create Account**:
   - Click "Sign up"
   - Enter email and password
   - Create organization

3. **Create Project**:
   - Click "Create Project"
   - Name: `librechat`
   - Environment: `prod` (default)

4. **Add Secrets**:
   - The script will display all required secrets
   - Copy-paste them into the Infisical web UI
   - Example secrets:
     ```
     CREDS_KEY=<auto-generated>
     CREDS_IV=<auto-generated>
     JWT_SECRET=<auto-generated>
     JWT_REFRESH_SECRET=<auto-generated>
     MEILI_MASTER_KEY=<auto-generated>
     OPENROUTER_API_KEY=sk-... (if you provided one)
     ```

5. **Create Machine Identity**:
   - Go to: Organization Settings → Access Control → Machine Identities
   - Click "Create identity"
   - Name: `k3d-librechat-operator`
   - Click "Add authentication method" → "Universal Auth"
   - **Copy the Client ID and Client Secret** (you'll need these next)

6. **Grant Access**:
   - Go to `librechat` project → Settings → Access Control
   - Add `k3d-librechat-operator` as Developer or Admin

7. **Continue Script**:
   - Return to terminal
   - Press Enter
   - Paste Client ID and Secret when prompted

### 4. Access LibreChat

Once deployment completes:

```bash
# LibreChat
http://chat.127.0.0.1.nip.io:30080

# Infisical
http://infisical.127.0.0.1.nip.io:30080
```

**First-time setup:**
1. Open LibreChat URL in your browser
2. Click "Sign up"
3. Create your account
4. Start chatting!

## Testing Features

### Test Secret Auto-Reload

1. Go to Infisical dashboard
2. Navigate to `librechat` project → `prod` environment
3. Update any secret (or add a new one)
4. Watch LibreChat pods automatically restart:
   ```bash
   kubectl get pods -n librechat -w
   ```
5. Within 60 seconds, pods should restart with new secrets!

### Test LLM Providers

```bash
# Add more API keys in Infisical
OPENROUTER_API_KEY=sk-or-...  # Access to 200+ models through one API
ANTHROPIC_API_KEY=sk-ant-...
GOOGLE_API_KEY=...

# LibreChat will automatically pick them up after pod restart
```

### Test File Uploads

1. In LibreChat, try uploading an image or PDF
2. Check MongoDB storage:
   ```bash
   kubectl exec -n librechat <mongodb-pod> -- mongosh --eval 'db.files.count()'
   ```

### Test Search Functionality

1. Have a few conversations in LibreChat
2. Use the search feature to find old messages
3. Check MeiliSearch indexes:
   ```bash
   kubectl logs -n librechat -l app.kubernetes.io/name=meilisearch
   ```

## Useful Commands

### Cluster Management

```bash
# List all k3d clusters
k3d cluster list

# Stop the cluster (keeps data)
k3d cluster stop librechat-test

# Start the cluster again
k3d cluster start librechat-test

# Delete the cluster (removes all data)
k3d cluster delete librechat-test
```

### Pod Management

```bash
# List all pods
kubectl get pods -n librechat
kubectl get pods -n infisical

# View logs
kubectl logs -n librechat -l app.kubernetes.io/name=librechat -f
kubectl logs -n infisical -l app.kubernetes.io/name=infisical -f

# Restart a deployment
kubectl rollout restart deployment/librechat -n librechat

# Get pod shell
kubectl exec -it -n librechat <pod-name> -- /bin/sh
```

### Secret Management

```bash
# View InfisicalSecret status
kubectl get infisicalsecret -n librechat
kubectl describe infisicalsecret librechat-credentials -n librechat

# View synced Kubernetes secret (base64 encoded)
kubectl get secret librechat-credentials-env -n librechat -o yaml

# Decode a specific secret
kubectl get secret librechat-credentials-env -n librechat -o jsonpath='{.data.OPENROUTER_API_KEY}' | base64 -d
```

### Debugging

```bash
# Check all resources
kubectl get all -n librechat

# Check ingresses
kubectl get ingress -A

# Check services
kubectl get svc -A

# Describe a failing pod
kubectl describe pod -n librechat <pod-name>

# View events
kubectl get events -n librechat --sort-by='.lastTimestamp'
```

## Common Issues

### Pods Stuck in Pending

**Symptom**: Pods show `Pending` status
**Cause**: Insufficient resources

```bash
# Check pod status
kubectl describe pod -n librechat <pod-name>

# Solution: Increase Docker resources
# Docker Desktop → Settings → Resources → Increase RAM/CPU
```

### Cannot Access Infisical/LibreChat

**Symptom**: URLs don't load
**Cause**: Port not forwarded or nginx not ready

```bash
# Check nginx ingress
kubectl get pods -n ingress-nginx

# Check ingresses
kubectl get ingress -A

# Verify port forwarding
k3d cluster list
# Should show: 30080:30080

# Solution: Recreate cluster with correct port mapping
k3d cluster delete librechat-test
k3d cluster create librechat-test --agents 1 -p "30080:30080@loadbalancer"
```

### Secrets Not Syncing

**Symptom**: `librechat-credentials-env` secret not created
**Cause**: Infisical Operator can't connect

```bash
# Check operator logs
kubectl logs -n infisical-operator-system -l control-plane=controller-manager

# Check InfisicalSecret status
kubectl describe infisicalsecret librechat-credentials -n librechat

# Common fixes:
# - Verify Client ID/Secret are correct
# - Ensure Machine Identity has project access
# - Check projectSlug matches exactly
```

### MongoDB Connection Errors

**Symptom**: LibreChat can't connect to MongoDB
**Cause**: MongoDB not ready or wrong credentials

```bash
# Check MongoDB status
kubectl get pods -n librechat -l app.kubernetes.io/name=mongodb

# View MongoDB logs
kubectl logs -n librechat -l app.kubernetes.io/name=mongodb

# Test connection
kubectl exec -n librechat <librechat-pod> -- env | grep MONGO
```

## Cleanup

### Keep Cluster, Reset LibreChat

```bash
# Delete LibreChat
helm uninstall librechat -n librechat

# Delete Infisical
helm uninstall infisical -n infisical

# Delete namespaces (will delete all data)
kubectl delete namespace librechat infisical

# Re-run bootstrap script
./bootstrap-local.sh
```

### Complete Cleanup

```bash
# Delete the entire cluster
k3d cluster delete librechat-test

# Remove any lingering Docker volumes
docker volume prune -f
```

## Migrating to Production

Once you've tested locally and everything works:

1. **Save your configuration**:
   - Document which secrets you're using
   - Note any custom librechat.yaml settings
   - Export your Infisical project structure

2. **Set up production infrastructure**:
   - Provision Linux server
   - Point domains to server IP
   - Ensure ports 80/443 are open

3. **Run production bootstrap**:
   ```bash
   # SSH into your server
   git clone <your-repo>
   cd LibreChat/k3s-librechat-deployment/scripts
   ./bootstrap-production.sh
   ```

4. **Key differences from local**:
   - Uses real domains instead of nip.io
   - SSL certificates via Let's Encrypt
   - Production-grade resource limits
   - Larger persistent volumes

5. **Migrate data (optional)**:
   ```bash
   # Export from local MongoDB
   kubectl exec -n librechat <mongo-pod> -- mongodump --archive > local-backup.archive

   # Import to production MongoDB
   kubectl exec -i -n librechat <mongo-pod> -- mongorestore --archive < local-backup.archive
   ```

## Tips & Best Practices

### Performance Tuning

For better local performance:

```bash
# Reduce resource requests
# Edit librechat-values.yaml and lower CPU/memory requests
# Then upgrade deployment:
helm upgrade librechat ... --values librechat-values.yaml
```

### Testing Updates

```bash
# Update LibreChat image
kubectl set image deployment/librechat librechat=ghcr.io/danny-avila/librechat:v0.7.0 -n librechat

# Watch rollout
kubectl rollout status deployment/librechat -n librechat
```

### Accessing Databases Directly

```bash
# MongoDB shell
kubectl exec -it -n librechat <mongodb-pod> -- mongosh

# MeiliSearch HTTP API
kubectl port-forward -n librechat svc/meilisearch 7700:7700
# Then open http://localhost:7700 in browser
```

### Saving Secrets for Later

The bootstrap script saves secrets to `/tmp/librechat-secrets-<timestamp>.txt`.

```bash
# Copy to safe location
cp /tmp/librechat-secrets-*.txt ~/librechat-secrets-backup.txt

# Or export from Infisical
# Go to Infisical → Project Settings → Export
```
